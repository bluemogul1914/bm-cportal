## 🔐 **Authentication & Permissions**

### **User Roles**
- **Admin** – Full access to admin dashboard
- **Client** – Access to client portal only

### **Session Management**
```php
$_SESSION['user_id']    // User ID
$_SESSION['user_name']  // Display name
$_SESSION['user_email'] // Email
$_SESSION['user_role']  // 'admin' or 'client'
```

### **Protected Routes**
All `admin-*.php` files check:
```php
if (!isset($_SESSION['user_id']) || $_SESSION['user_role'] !== 'admin') {
    header('Location: index.php');
    exit();
}
```

## 🚀 **Deployment Instructions**

### **On Coolify (Production)**

1. **Upload files** to `/var/www/html/`:
   ```bash
   cd /var/www/html
   
   # Upload these new files:
   - admin-dashboard.php
   - admin-clients.php
   - admin-ai-agents.php
   - includes/admin-sidebar.php
   - assets/css/admin.css
   ```

2. **Update database**:
   ```bash
   mysql -h [host] -u [user] -p[password] bluemogul_portal < database/admin-schema.sql
   ```

3. **Create admin user**:
   ```sql
   UPDATE users SET role = 'admin' WHERE email = 'admin@bluemogul.biz';
   ```

4. **Test access**:
   - Visit: `https://controlpanel.bluemogul.us/admin-dashboard.php`
   - Login with admin credentials

### **On Replit (Development)**

1. **Copy files** to your Replit project
2. **Run setup**: Visit `/setup.php` to create tables
3. **Create admin**:
   ```php
   // In setup.php, add:
   $pdo->query("UPDATE users SET role = 'admin' WHERE id = 1");
   ```
4. **Test**: Visit `/admin-dashboard.php`

## 📈 **Dashboard Metrics Explained**

### **MRR Calculation**
```php
SUM(p.price) 
FROM subscriptions s 
JOIN products p ON s.product_id = p.id 
WHERE s.status = 'active' AND p.billing_period = 'monthly'
```

### **ARR Calculation**
```php
ARR = MRR × 12
```

### **Growth Rate**
```php
growth_rate = ((new_clients_this_month - prev_month_clients) / prev_month_clients) × 100
```

### **Churn Rate**
```php
churn_rate = (cancelled_this_month / total_active_clients) × 100
```

## 📞 **Support & Troubleshooting**

### **Common Issues**

**Dashboard not loading**
- Check `$_SESSION['user_role'] === 'admin'`
- Verify database connection in `config.php`

**Charts not rendering**
- Ensure Chart.js CDN is loaded
- Check browser console for errors

**Sidebar menu not appearing**
- Verify `includes/admin-sidebar.php` exists
- Check file permissions

**AI Agent stats showing zero**
- Run `agent_logs` table creation script
- Insert test log entries
